==============================================================
  android-patches / MANIFEST_CHANGES.txt
==============================================================
Apply these edits to android/app/src/main/AndroidManifest.xml
AFTER running  "npx cap add android".

The file is generated by Capacitor. Look for the <activity>
tag whose name is com.getcapacitor.BridgeActivity and add the
two attributes marked with  ← ADD  below.
==============================================================

<activity
    android:configChanges="orientation|keyboardHidden|keyboard|screenSize|locale|smallestScreenSize|screenLayout|uiMode"
    android:hardwareAccelerated="true"                ← ADD (confirm true)
    android:label="@string/title_activity_main"
    android:launchMode="singleTask"
    android:name="com.getcapacitor.BridgeActivity"
    android:screenOrientation="portrait"              ← ADD
    android:theme="@style/AppTheme.NoActionBarLaunch"
    android:exported="true">

--------------------------------------------------------------
Internet permission (usually already added by Capacitor,
but double-check it exists at the top of the manifest):

    <uses-permission android:name="android.permission.INTERNET" />

--------------------------------------------------------------
Hardware acceleration on the whole application tag (fallback):

    <application
        ...
        android:hardwareAccelerated="true"            ← confirm
        ...>
